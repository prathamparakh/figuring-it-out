# Figuring It Out

A collection of projects, experiments, notes, and technical blogs documenting what I am learning by building things myself.

## Why This Repository Exists

There is a difference between knowing that something works and understanding why it works.I created this repository to close that gap.

Whenever I want to learn a new concept, technology, programming technique, or tool, I want to understand it by actually building something with it.

The process is simple:

1. Find something I want to understand.
2. Build a small project around it.
3. Research the concepts required to build it.
4. Write the code myself.
5. Document what I learned.
6. Commit the project to Git.
7. Keep improving it over time.

The goal is not to create perfect software.

The goal is to **figure things out**.
